# 2026-10-07 — The fun pass: what's left for a cheaper window

Already decided; see DECISIONS 2026-10-07 (later) and don't re-open: adjacency is read off the
figure's geometry and the map's columns (`getStruckArea`), offered as a default and put to him as
UPSTREAM 118; the mini figure on a card is positioned boxes, not an SVG; item icons are Foundry's
own svg set; a chosen image is never replaced.

1. **Live checks in a running V14**, ticked off here: the attack dialog's aim picker (DialogV2's
   `render` callback and the click setting the select); a new Item taking its type's icon
   (`getDefaultArtwork`); a re-import giving the packs theirs; the fumble marker landing the right
   distance (a 5' grid, 12' thrown = 2.4 squares); Place on a creature card (cone angle, ray width);
   Roll on a rider; the second token bar in the token config; `<prose-mirror toggled>` saving a
   description; the mini figure surviving the chat sanitiser (if its inline styles are stripped,
   switch `renderBodyMini` to one `<svg>` and test that instead); the just-hit flash.
2. **The dartboard diagram itself.** The board's Epic 3 row still wants the attack chart drawn as
   his bullseye (wedges with the roll bands, Called Shot and Miss(Short) call-outs, one per hand),
   redesigned for Foundry. Pure visualisation of `ATTACK_CHARTS` (`combat-tables.mjs`); the
   numbers exist. Done when the Combat tab shows it for the current attack skill and Lore skill.
3. **The slash.** A cut that sweeps a row of areas rather than one. Not designed; the mockup
   approximated it as "every area in the aim's row". Ask the user before building.
4. **Creature attack dialog dials.** The character's attack dialog has the called-shot bonus and
   fumble range fields; the creature's (`askCreatureAttackOptions` or its equivalent in
   `creature-attack.mjs`) does not yet. Add the same two fields and pass them to `resolveAttack`.
5. **Rider saves for the weapon card.** `getTriggeredEffects` and the Roll button exist on the
   creature card only; a poisoned weapon's card posts its own poison card instead. Fine as is;
   note it if anyone asks.
6. **Items already in a world.** `populateItems()` copies carry the bag until cleared and
   populated again; a data fix could set `img` on world items still wearing it (`isDefaultItemImage`).
7. **Marker clean-up.** Fumble markers are plain drawings; a "clear Imagine markers" button in the
   round clock window would tidy a long fight. Flag them (`flags.imagine-rpg.marker`) first.

Everything in `docs/sonnet/2026-10-07-quality-pass.md` still stands.
