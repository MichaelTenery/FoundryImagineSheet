them under a name the matcher can reach. They are marked rather than left blank so that a
gap is something you can search for, and the item sheet shows the XXX in red. XXX is
deliberately NOT a switchable sourcebook -- see `getSourcebookId` in

released, so content of his drawn from it can be named but never page-referenced,
and some of the list below will never resolve to a book anyone can open. A non-zero
count here is not by itself unfinished work.

To fix one: type the book and page over the XXX on the item sheet, or add an entry to
`src/packs/manual/<pack>.json` with `"_override": true` so a rebuild keeps it.
